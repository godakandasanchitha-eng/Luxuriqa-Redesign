# Luxuriqa Automobile

**Modern Luxury Automobile Showcase Website**

---

## 📌 Project Overview

Luxuriqa Automotive is a premium front-end web project designed to simulate a luxury car dealership experience.  
The website focuses on immersive browsing, cinematic UI structure, and conversion-driven design for vehicle discovery.

---

## 🎯 Purpose

The goal of this project is to create a modern, responsive automobile website using only:

- HTML
- CSS
- Vanilla JavaScript

It emphasizes user experience, visual storytelling, and structured navigation through cars by style and brand.

---

## 🧩 Core Features

- Browse Cars by Style (SUV, Sedan, Sports, Electric, Hybrid, Luxury SUV)
- Browse Cars by Make & Model (BMW, Mercedes, Audi, Toyota, etc.)
- Expandable brand cards with model previews
- Interactive UI with hover and click animations
- Modern dark luxury design system
- Fully responsive layout (desktop-first approach)

---

### Project Structure Overview

- index.html → Main entry point
- assets/ → Images, icons, logos
- css/ → Styling files
- js/ → JavaScript logic & animations
- components/ → Reusable UI blocks
- pages/ → Additional pages (inventory, details)

---

The design follows a **luxury automotive aesthetic** inspired by high-end brands such as Tesla, BMW, and Mercedes-Benz.
